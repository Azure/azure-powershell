# Get-AzNetworkSecurityOperation

## SYNOPSIS
Lists operations supported by the Microsoft.NetworkSecurity provider.

## SYNTAX

```
Get-AzNetworkSecurityOperation [-DefaultProfile <PSObject>]
 [<CommonParameters>]
```

## DESCRIPTION
Lists operations supported by the Microsoft.NetworkSecurity provider.

## EXAMPLES

### Example 1: List provider operations
```powershell
Get-AzNetworkSecurityOperation
```

Lists the operations supported by Microsoft.NetworkSecurity.
