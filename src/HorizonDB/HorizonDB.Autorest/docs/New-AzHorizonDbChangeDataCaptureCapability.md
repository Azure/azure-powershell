# New-AzHorizonDbChangeDataCaptureCapability

## SYNOPSIS
Create or replaces the singleton change data capture capability and reconciles shared engine prerequisites.

## SYNTAX

### CreateExpanded (Default)
```
New-AzHorizonDbChangeDataCaptureCapability -ClusterName <String> -ResourceGroupName <String>
 [-SubscriptionId <String>] [-AutoUpgradeExtension] [-DesiredState <String>] [-DefaultProfile <PSObject>]
 [-AsJob] [-NoWait] [-Confirm] [-WhatIf] [<CommonParameters>]
```

### CreateViaJsonFilePath
```
New-AzHorizonDbChangeDataCaptureCapability -ClusterName <String> -ResourceGroupName <String>
 -JsonFilePath <String> [-SubscriptionId <String>] [-DefaultProfile <PSObject>] [-AsJob] [-NoWait] [-Confirm]
 [-WhatIf] [<CommonParameters>]
```

### CreateViaJsonString
```
New-AzHorizonDbChangeDataCaptureCapability -ClusterName <String> -ResourceGroupName <String>
 -JsonString <String> [-SubscriptionId <String>] [-DefaultProfile <PSObject>] [-AsJob] [-NoWait] [-Confirm]
 [-WhatIf] [<CommonParameters>]
```

## DESCRIPTION
Create or replaces the singleton change data capture capability and reconciles shared engine prerequisites.

## EXAMPLES

### Example 1: Enable change data capture with automatic extension upgrades
```powershell
New-AzHorizonDbChangeDataCaptureCapability -ResourceGroupName 'example-resource-group' -ClusterName 'example-cluster' -DesiredState 'Enabled' -AutoUpgradeExtension | Format-List -Property Name, DesiredState, EffectiveState, AutoUpgradeExtension, ProvisioningState
```

```output
Name                 : default
DesiredState         : Enabled
EffectiveState       : Enabled
AutoUpgradeExtension : True
ProvisioningState    : Succeeded
```

Sample output from the HTTP 200 response.
Values are illustrative REST response data, not a live execution result.
