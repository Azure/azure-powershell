# Update-AzHorizonDbChangeDataCaptureDestination

## SYNOPSIS
Update mutable change data capture destination properties.
Omitted properties preserve their current values.

## SYNTAX

### UpdateExpanded (Default)
```
Update-AzHorizonDbChangeDataCaptureDestination -ClusterName <String> -DestinationName <String>
 -ResourceGroupName <String> [-SubscriptionId <String>] [-DesiredState <String>] [-DefaultProfile <PSObject>]
 [-AsJob] [-NoWait] [-Confirm] [-WhatIf] [<CommonParameters>]
```

### UpdateViaIdentityClusterExpanded
```
Update-AzHorizonDbChangeDataCaptureDestination -ClusterInputObject <IHorizonDbIdentity>
 -DestinationName <String> [-DesiredState <String>] [-DefaultProfile <PSObject>] [-AsJob] [-NoWait] [-Confirm]
 [-WhatIf] [<CommonParameters>]
```

### UpdateViaIdentityExpanded
```
Update-AzHorizonDbChangeDataCaptureDestination -InputObject <IHorizonDbIdentity> [-DesiredState <String>]
 [-DefaultProfile <PSObject>] [-AsJob] [-NoWait] [-Confirm] [-WhatIf] [<CommonParameters>]
```

### UpdateViaJsonFilePath
```
Update-AzHorizonDbChangeDataCaptureDestination -ClusterName <String> -DestinationName <String>
 -ResourceGroupName <String> -JsonFilePath <String> [-SubscriptionId <String>] [-DefaultProfile <PSObject>]
 [-AsJob] [-NoWait] [-Confirm] [-WhatIf] [<CommonParameters>]
```

### UpdateViaJsonString
```
Update-AzHorizonDbChangeDataCaptureDestination -ClusterName <String> -DestinationName <String>
 -ResourceGroupName <String> -JsonString <String> [-SubscriptionId <String>] [-DefaultProfile <PSObject>]
 [-AsJob] [-NoWait] [-Confirm] [-WhatIf] [<CommonParameters>]
```

## DESCRIPTION
Update mutable change data capture destination properties.
Omitted properties preserve their current values.
