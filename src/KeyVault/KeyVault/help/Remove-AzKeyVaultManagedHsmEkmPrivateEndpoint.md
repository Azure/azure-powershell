# Remove-AzKeyVaultManagedHsmEkmPrivateEndpoint

## SYNOPSIS
Deletes an outbound External Key Manager private endpoint from a Managed HSM (preview).

## SYNTAX

### ByHsmName (Default)
```
Remove-AzKeyVaultManagedHsmEkmPrivateEndpoint -Name <String> [-NoWait] [-HsmName] <String>
 [-DefaultProfile <IAzureContextContainer>] [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm]
 [-AcquirePolicyToken] [-ChangeReference <String>] [<CommonParameters>]
```

### ByHsmId
```
Remove-AzKeyVaultManagedHsmEkmPrivateEndpoint -Name <String> [-NoWait] [-HsmId] <String>
 [-DefaultProfile <IAzureContextContainer>] [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm]
 [-AcquirePolicyToken] [-ChangeReference <String>] [<CommonParameters>]
```

### ByInputObject
```
Remove-AzKeyVaultManagedHsmEkmPrivateEndpoint -Name <String> [-NoWait] [-HsmObject] <PSManagedHsm>
 [-DefaultProfile <IAzureContextContainer>] [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm]
 [-AcquirePolicyToken] [-ChangeReference <String>] [<CommonParameters>]
```

## DESCRIPTION
Deletes the named outbound External Key Manager (EKM) private endpoint. The service rejects deletion while the active EKM connection references the endpoint. The command never deletes or replaces the active connection automatically.

By default the command requests confirmation, waits for the delete operation, and returns its status and job ID. `NoWait` submits deletion without polling or operation output. This command is in preview.

## EXAMPLES

### Example 1: Delete an unused endpoint
```powershell
Remove-AzKeyVaultManagedHsmEkmPrivateEndpoint -HsmName testmhsm -Name pe2
```

Requests confirmation before deleting the endpoint and waits for the service operation to complete.
