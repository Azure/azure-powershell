# Get-AzRecoveryServicesBackupRecoveryLogChain

## SYNOPSIS
This command lists the start and end points of the unbroken log chain of the given backup item. Use it to determine whether the point-in-time, to which the user wants the DB to be restored, is valid or not.

## SYNTAX

### NoFilterParameterSet (Default)
```
Get-AzRecoveryServicesBackupRecoveryLogChain [-Item] <ItemBase> [-UseSecondaryRegion]
 [-BaseSnapshotRecoveryPointId <String>] [-BaseRecoveryPointDatasourceId <String>] [-RecoveryMode <String>]
 [-VaultId <String>] [-DefaultProfile <IAzureContextContainer>] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

### DateTimeFilter
```
Get-AzRecoveryServicesBackupRecoveryLogChain [[-StartDate] <DateTime>] [[-EndDate] <DateTime>]
 [-Item] <ItemBase> [-UseSecondaryRegion] [-BaseSnapshotRecoveryPointId <String>]
 [-BaseRecoveryPointDatasourceId <String>] [-RecoveryMode <String>] [-VaultId <String>]
 [-DefaultProfile <IAzureContextContainer>] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION
The **Get-AzRecoveryServicesBackupRecoveryLogChain** cmdlet gets the time range recovery points in time for a backed up Azure Backup item.
After an item has been backed up, an **AzRecoveryServicesBackupRecoveryLogChain** object has one or more recovery time ranges.

## EXAMPLES

### Example 1
```powershell
$StartDate = (Get-Date).AddDays(-7)
$EndDate = Get-Date
$Container = Get-AzRecoveryServicesBackupContainer -ContainerType AzureWorkload
$RP = Get-AzRecoveryServicesBackupItem -Container $Container -WorkloadType MSSQL | Get-AzRecoveryServicesBackupRecoveryLogChain -StartDate $Startdate.ToUniversalTime() -EndDate $Enddate.ToUniversalTime()
```

The first command gets the date from seven days ago, and then stores it in the $StartDate variable.
The second command gets today's date, and then stores it in the $EndDate variable.
The third command gets AzureWorkload backup containers, and stores them in the $Container variable.
The fourth command gets the backup item, and then shares it across the piped cmdlet as backup item object.
The last command gets an array of recovery point time ranges for the item in $BackupItem, and then stores them in the $RP variable.

### Example 3: Get database log ranges for a SQL Instance snapshot

```powershell
$container = Get-AzRecoveryServicesBackupContainer -ContainerType AzureVMAppContainer `
    -BackupManagementType AzureWorkload -FriendlyName "sql-vm" -VaultId $vault.ID
$instance = Get-AzRecoveryServicesBackupItem -Container $container `
    -WorkloadType MSSQLInstance -Name "SQLInstance;mssqlserver" -VaultId $vault.ID
$snapshot = Get-AzRecoveryServicesBackupRecoveryPoint -Item $instance `
    -RestorePointQueryType Snapshot -GetLatestRecoveryPointOnly -VaultId $vault.ID
$snapshot = Get-AzRecoveryServicesBackupRecoveryPoint -Item $instance `
    -RecoveryPointId $snapshot.RecoveryPointId -VaultId $vault.ID
$database = $snapshot.IncludedDatabases[0]
$databaseItem = Get-AzRecoveryServicesBackupItem -Container $container `
    -WorkloadType MSSQL -Name "SQLDataBase;$($database.DatasourceName)" -VaultId $vault.ID
Get-AzRecoveryServicesBackupRecoveryLogChain -Item $databaseItem `
    -BaseSnapshotRecoveryPointId $snapshot.RecoveryPointId `
    -BaseRecoveryPointDatasourceId $instance.ProtectedItemDataSourceId `
    -RecoveryMode SnapshotAttachAndRecover -VaultId $vault.ID
```

This example lists log time ranges for a database included in an existing SQL Instance snapshot.
The item is the database item, while the base datasource ID belongs to the protected SQL Instance, not the included database.
The database must have log backups available. StartDate and EndDate can also be supplied to limit the queried time range.
Without snapshot-context parameters, the command continues to list the item's ordinary log ranges.

### -RecoveryMode
Filters SQL log ranges by snapshot recovery mode. Accepted values are SnapshotAttachAndRecover, SnapshotAttach, and RecoveryUsingSnapshot.
For log replay on top of a base snapshot, use SnapshotAttachAndRecover with BaseSnapshotRecoveryPointId and BaseRecoveryPointDatasourceId.
The command returns time ranges only; it does not execute a restore.
