# Set-AzResilienceUsagePlan

## SYNOPSIS
Update a UsagePlan

## SYNTAX

### UpdateExpanded (Default)
```
Set-AzResilienceUsagePlan -Name <String> -ResourceGroupName <String> [-SubscriptionId <String>]
 -Location <String> [-PlanType <String>] [-Tag <Hashtable>] [-DefaultProfile <PSObject>] [-AsJob] [-NoWait]
 [-WhatIf] [-Confirm] [<CommonParameters>]
```

### Update
```
Set-AzResilienceUsagePlan -Name <String> -ResourceGroupName <String> [-SubscriptionId <String>]
 -Resource <IUsagePlan> [-DefaultProfile <PSObject>] [-AsJob] [-NoWait]
 [-WhatIf] [-Confirm] [<CommonParameters>]
```

### UpdateViaJsonFilePath
```
Set-AzResilienceUsagePlan -Name <String> -ResourceGroupName <String> [-SubscriptionId <String>]
 -JsonFilePath <String> [-DefaultProfile <PSObject>] [-AsJob] [-NoWait]
 [-WhatIf] [-Confirm] [<CommonParameters>]
```

### UpdateViaJsonString
```
Set-AzResilienceUsagePlan -Name <String> -ResourceGroupName <String> [-SubscriptionId <String>]
 -JsonString <String> [-DefaultProfile <PSObject>] [-AsJob] [-NoWait]
 [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Update a UsagePlan

## EXAMPLES

### Example 1: Replace a usage plan
```powershell
Set-AzResilienceUsagePlan `
  -Name 'up-payments' `
  -ResourceGroupName 'rg-resiliency-prod' `
  -Location 'eastus'
```

Replaces the specified usage plan.
Properties that are not supplied are reset.
