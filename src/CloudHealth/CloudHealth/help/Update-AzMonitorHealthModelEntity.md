# Update-AzMonitorHealthModelEntity

## SYNOPSIS

Update a Entity

## SYNTAX

### UpdateExpanded (Default)

```
Update-AzMonitorHealthModelEntity -HealthModelName <string> -Name <string>
 -ResourceGroupName <string> [-SubscriptionId <string>] [-CanvaPositionX <float>]
 [-CanvaPositionY <float>] [-DegradedActionGroupId <string[]>] [-DegradedDescription <string>]
 [-DegradedSeverity <string>] [-DisplayName <string>] [-HealthObjective <float>]
 [-IconCustomData <string>] [-IconName <string>] [-Impact <string>] [-SignalGroup <ISignalGroups>]
 [-Tag <hashtable>] [-UnhealthyActionGroupId <string[]>] [-UnhealthyDescription <string>]
 [-UnhealthySeverity <string>] [-DefaultProfile <psobject>] [-AsJob] [-NoWait] [-WhatIf] [-Confirm]
```

### UpdateViaIdentityExpanded

```
Update-AzMonitorHealthModelEntity -InputObject <ICloudHealthIdentity> [-CanvaPositionX <float>]
 [-CanvaPositionY <float>] [-DegradedActionGroupId <string[]>] [-DegradedDescription <string>]
 [-DegradedSeverity <string>] [-DisplayName <string>] [-HealthObjective <float>]
 [-IconCustomData <string>] [-IconName <string>] [-Impact <string>] [-SignalGroup <ISignalGroups>]
 [-Tag <hashtable>] [-UnhealthyActionGroupId <string[]>] [-UnhealthyDescription <string>]
 [-UnhealthySeverity <string>] [-DefaultProfile <psobject>] [-AsJob] [-NoWait] [-WhatIf] [-Confirm]
```

```
Update-AzMonitorHealthModelEntity -Name <string> -HealthmodelInputObject <ICloudHealthIdentity>
 [-CanvaPositionX <float>] [-CanvaPositionY <float>] [-DegradedActionGroupId <string[]>]

 [-HealthObjective <float>] [-IconCustomData <string>] [-IconName <string>] [-Impact <string>]
 [-SignalGroup <ISignalGroups>] [-Tag <hashtable>] [-UnhealthyActionGroupId <string[]>]

 [-AsJob] [-NoWait] [-WhatIf] [-Confirm]
```
