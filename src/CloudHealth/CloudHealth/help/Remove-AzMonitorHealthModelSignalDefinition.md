# Remove-AzMonitorHealthModelSignalDefinition

## SYNOPSIS

Delete a SignalDefinition

## SYNTAX

### Delete (Default)

```
Remove-AzMonitorHealthModelSignalDefinition -HealthModelName <string> -Name <string>
 -ResourceGroupName <string> [-SubscriptionId <string>] [-DefaultProfile <psobject>] [-AsJob]
 [-NoWait] [-PassThru] [-WhatIf] [-Confirm]
```

### DeleteViaIdentity

```
Remove-AzMonitorHealthModelSignalDefinition -InputObject <ICloudHealthIdentity>
 [-DefaultProfile <psobject>] [-AsJob] [-NoWait] [-PassThru] [-WhatIf] [-Confirm]
```

### DeleteViaIdentityHealthmodel

```
Remove-AzMonitorHealthModelSignalDefinition -Name <string>
 -HealthmodelInputObject <ICloudHealthIdentity> [-DefaultProfile <psobject>] [-AsJob] [-NoWait]
 [-PassThru] [-WhatIf] [-Confirm]
```
