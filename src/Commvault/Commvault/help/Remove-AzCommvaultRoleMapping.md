# Remove-AzCommvaultRoleMapping

## SYNOPSIS
Delete a RoleMapping

## SYNTAX

### Delete (Default)
```
Remove-AzCommvaultRoleMapping -CloudAccountName <String> -ResourceGroupName <String> [-SubscriptionId <String>]
 [-DefaultProfile <PSObject>] [-PassThru] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

### DeleteViaIdentity
```
Remove-AzCommvaultRoleMapping -InputObject <ICommvaultIdentity> [-DefaultProfile <PSObject>] [-PassThru]
 [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Delete a RoleMapping

## EXAMPLES

### Example 1: Delete the role mapping of a cloud account
```powershell
Remove-AzCommvaultRoleMapping -ResourceGroupName rg-commvault -CloudAccountName cca-contoso
```

Deletes the role mapping of the cloud account.
