# Update-AzStorageContextCache

## SYNOPSIS
Update a Context Cache.

## SYNTAX

### UpdateExpanded (Default)
```
Update-AzStorageContextCache -Name <String> -ResourceGroupName <String> [-SubscriptionId <String>]
 [-CustomerManagedKeyEncryptionKeyUrl <String>] [-Description <String>]
 [-EnableSystemAssignedIdentity <Boolean?>] [-EncryptionInfrastructureEncryption <String>]
 [-KeyEncryptionKeyIdentityDelegatedIdentityClientId <String>]
 [-KeyEncryptionKeyIdentityFederatedClientId <String>] [-KeyEncryptionKeyIdentityType <String>]
 [-KeyEncryptionKeyIdentityUserAssignedIdentityResourceId <String>] [-Tag <Hashtable>]
 [-UserAssignedIdentity <String[]>] [-DefaultProfile <PSObject>] [-AsJob] [-NoWait] [-Confirm] [-WhatIf]
 [<CommonParameters>]
```

### UpdateViaIdentityExpanded
```
Update-AzStorageContextCache -InputObject <IStorageIdentity> [-CustomerManagedKeyEncryptionKeyUrl <String>]
 [-Description <String>] [-EnableSystemAssignedIdentity <Boolean?>]
 [-EncryptionInfrastructureEncryption <String>] [-KeyEncryptionKeyIdentityDelegatedIdentityClientId <String>]
 [-KeyEncryptionKeyIdentityFederatedClientId <String>] [-KeyEncryptionKeyIdentityType <String>]
 [-KeyEncryptionKeyIdentityUserAssignedIdentityResourceId <String>] [-Tag <Hashtable>]
 [-UserAssignedIdentity <String[]>] [-DefaultProfile <PSObject>] [-AsJob] [-NoWait] [-Confirm] [-WhatIf]
 [<CommonParameters>]
```

## DESCRIPTION
Update a Context Cache.

## EXAMPLES

### Example 1: Change a context cache description
```powershell
Update-AzStorageContextCache -ResourceGroupName "myResourceGroup" -Name "mycontextcache" -Description "Updated inference context cache"
```

Updates the description without sending unrelated encryption or identity settings.
